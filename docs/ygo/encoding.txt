package encoding // import "github.com/reearth/ygo/encoding"

Package encoding implements the lib0 binary encoding format used by Yjs.

This is a variable-length binary codec with no external dependencies. It is the
foundation for all wire-format serialisation in ygo.

Reference: https://github.com/dmonad/lib0
